# 🛒 বাজার দর (Bazar-Dor)

## 📝 Description

BazarDor is a web-based market price tracking platform that helps users explore daily prices of essential commodities across different markets in Bangladesh. Users can view price changes, compare market rates, and stay updated on everyday product prices.

## 🛠️ Technologies Used

- **Next.js 16** – React framework
- **React 19** – UI development
- **TypeScript** – Type safety
- **Tailwind CSS 4** – Styling
- **DaisyUI 5** – UI components
- **MongoDB** – Database
- **Better Auth** – Authentication
- **Lucide React & React Icons** – Icons

## ✨ Key Features

1. **Daily Market Prices:** Explore updated prices of essential commodities.
2. **Category-Based Browsing:** Browse products by categories such as rice, fish, vegetables, meat, and more.
3. **Price Comparison:** Compare today's prices with yesterday, last week, and last month.
4. **Market-Wise Price Details:** View minimum, maximum, and average prices across different markets and divisions.
5. **User Authentication:** Secure user registration and sign-in functionality.
